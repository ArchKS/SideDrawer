# SideDrawer

macOS 原生侧边文件抽屉。文件或目录拖入后会被移动到 SideDrawer 的本地存储中，而不是复制。

## 已实现

- 每个抽屉都是独立、始终置顶的磨砂玻璃悬浮长条
- 每个抽屉可单独拖动，并以零间距自动吸附 macOS 可用屏幕的上下左右四边
- 每个抽屉带独立图钉按钮，固定后保持原位且不可拖动
<!-- ai coding: 更新多收纳盒快捷键目标选择与菜单说明 2026/09/17: 10:55 -->
- 抽屉厚度缩为原来的一半；名称无边框并与数量同排，-45° 图钉位于右上角
- 新建、保存和删除空抽屉三个操作图标已隐藏；顶部关闭按钮可删除当前空收纳盒
- 文件拖到抽屉上时显示“松开放入”动画提示；左右吸附时调节柄在底部水平居中，上下吸附时在右侧垂直居中
- SideDrawer 显示在程序坞和应用切换器中，支持 `Command+Q` 退出，并可从菜单中在访达定位应用
- 吸附上下边缘时横向排列，吸附左右边缘时纵向排列
- 所有抽屉同时展开，无需标签切换
- 每个抽屉最多直观显示 5 个位置；超过 5 项时，第 5 位显示 macOS 风格文件堆叠，点击可展开
- 新建和命名多个抽屉；普通显示时名称无光标，新建窗口激活后自动选中默认名称并可直接键盘改名
<!-- ai coding: 补充当前抽屉的新建、全选、删除所选和保存快捷键 2026/09/17: 09:51 -->
- 当前抽屉激活后支持 `Command+N` 新建抽屉、`Command+A` 全选、`Delete` 将所选项目移到废纸篓、`Command+S` 将整个抽屉保存为文件夹
- 顶部“收纳盒”菜单和右上角状态菜单会显示上述操作及对应快捷键
<!-- ai coding: 补充菜单尺寸输入和 Command+V 粘贴文件内容说明 2026/09/17: 14:25 -->
- 菜单支持手动输入抽屉尺寸：上下贴边输入高度，左右贴边输入宽度，单位为像素
- 抽屉激活时按 `Command+V` 可粘贴文件或文件夹；图片保存为 PNG，Markdown 文本保存为 `.md`，普通文本保存为 `.txt`
- 全选后拖动任一已选项，可将整组文件和目录移到 Finder 文件夹
- 可从菜单栏录制自定义移动快捷键；Finder 位于前台时，一个收纳盒直接移动，多个收纳盒会直接列出全部目标，点击名称即移动，无需二次确认
- 全局快捷键使用 macOS 原生热键机制，不需要辅助功能权限；首次读取 Finder 选择时仍需允许自动化权限
- 从 Finder 拖入文件和目录，原位置随移动操作清空
- 从抽屉拖到 Finder，或通过右键菜单明确移动到其他文件夹
- 文件拖出并完成移动后，抽屉会自动清除对应项目
- 将整个抽屉保存为同名文件夹
- 菜单栏图标用于新建、显示全部、隐藏全部和退出

- 快捷键移动成功后立即刷新访达前窗口，原位置的文件即时消失
- 抽屉接收拖入或粘贴的文件后同样刷新访达，避免外部视图残留已移动的项目
- 抽屉设置写盘失败时弹出提示并给出原因，不再静默丢失名称、位置或尺寸改动

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `Sources/SideDrawer/SDCommon.{h,m}` | 共享常量、菜单文案、错误与访达刷新工具 |
| `Sources/SideDrawer/SDDrawerStore.{h,m}` | 抽屉元数据与文件存储层 |
| `Sources/SideDrawer/SDDrawerContentView.{h,m}` | 抽屉内容视图、文件卡片与堆叠项 |
| `Sources/SideDrawer/SDDrawerPanel.{h,m}` | 抽屉窗口、吸附与尺寸控制 |
| `Sources/SideDrawer/SDShortcutRecorder.{h,m}` | 全局快捷键录制与展示 |
| `Sources/SideDrawer/SDDrawerChoicePanel.{h,m}` | 多收纳盒目标选择面板 |
| `Sources/SideDrawer/SDAppDelegate.{h,m}` | 应用生命周期、菜单与快捷键流程 |
| `Sources/SideDrawer/main.m` | 进程入口与自检 |

## 构建

```sh
./build-app.sh
```

构建结果位于 `outputs/SideDrawer.app`。首次启动如被 macOS 拦截，请在 Finder 中右键应用并选择“打开”。

应用数据存放于 `~/Library/Application Support/SideDrawer`。
